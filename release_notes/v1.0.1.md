# ThemeForge v1.0.1

This patch release bundles four internal iterations completed after v1.0.0.

## Updated

### Multi-file review workspace

- Added tabbed raw transcript viewing for multiple uploaded files.
- Kept one shared focus topic across the full multi-file analysis.
- Reworked the evidence panel to highlight raw transcript passages using each
  theme's color.
- Added previous and next quote navigation for the selected theme.
- Removed duplicate action controls so file selection, analysis, and export
  each appear once in the workspace.
- Added light and dark window modes.
- Added an About dialog with project, repository, archive DOI, license, and
  developer information.
- Stabilized selected-theme transcript highlighting across multiple transcript
  tabs.
- Fixed quote navigation for cases where a selected theme appears in one file
  but not every uploaded file.

### Interview-noise filtering

- Filtered interviewer, moderator, facilitator, researcher, and similar
  procedural speaker turns from theme generation.
- Filtered common interview consent and procedure language, including recording,
  voluntary participation, confidentiality, and before-we-start instructions.
- Added speaker-role profiling so named interviewers or moderators, such as
  real names attached to interview prompts, are excluded from theme generation
  and quote evidence.
- Improved quote evidence accuracy so themes are built from participant
  perspective content rather than interview setup language.

### Evidence transparency

- Merged duplicate same-label themes so related evidence appears under one
  theme instead of split repeated theme names.
- Added quote-selection rationale for each highlighted quote, including theme
  signals, focus-topic alignment, similarity score, and researcher-review
  reminder.
- Added quote rationale to Markdown and CSV exports.

## Verification

- Unit tests cover analysis behavior, imports, CLI multi-file use, release
  metadata, and UI view-model helpers.
- Compile checks cover the ThemeForge package, tests, and GUI launcher.
- Focused validation confirmed interviewer procedure text and named
  interviewer prompts no longer become themes or quote evidence.
- GUI smoke validation covered transcript tabs, shared focus-topic analysis,
  selected-theme quote navigation, quote rationale, and dark mode.
