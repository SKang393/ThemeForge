# ThemeForge v1.4.0

## Added

- Theme-by-source and theme-by-speaker matrices show quote counts and
  unique-span coverage.
- Rigor tools provides views for matrices, intercoder reliability,
  disagreement review, the audit log, and CSV exports.
- Two-project comparison evaluates `.tfproj` projects over identical
  transcript text and shared meaning units, reporting percent agreement and
  Cohen's kappa.
- Persistent coder identity and audit events are stored in `.tfproj` files.

## Reliability Method

- Intercoder comparison applies to two `.tfproj` files with identical
  transcript text and shared meaning units.
- Reports include per-theme percent agreement, Cohen's kappa, prevalence or
  undefined-kappa warnings, and side-by-side disagreements for researcher
  review.

## Fixed

- A failed or no-analysis comparison now clears earlier reliability and
  disagreement rows before reporting the problem.
- An open Rigor tools window now refreshes to empty matrix and intercoder views
  when the current project has no analysis result.
- Audit, matrix, reliability, and disagreement CSV exports now neutralize
  formula-leading cells; disagreement exports also disambiguate duplicate or
  reserved coder headings.

## Verification

Release publication uses these gates:

- Full `unittest` discovery.
- `compileall` across application and test sources.
- Local codebook validation.
- Packaged Windows GUI exercise covering matrices, intercoder reliability,
  the audit log, manual refresh, and unsupported-format error handling.
- Portable ZIP inventory inspection.

## Portable Scope

- Optional sentence-transformer and `kiwipiepy` dependencies remain available
  to source installations and are not bundled in the default portable ZIP.
- The portable package scope remains local and offline, with no online service
  required for transcript text.
