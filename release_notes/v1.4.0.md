# ThemeForge v1.4.0

## Updated

- Added **Remove files** and **Remove** controls for clearing selected
  transcripts and codebooks without deleting the original files.
- Added `.tfproj` project save, open, and autosave support for cached
  transcripts, settings, analysis results, and manual coding work.
- Added manual theme renaming, keyword editing, hierarchy, merging, splitting,
  quote reassignment, uncoding, and quote-boundary editing.
- Added arbitrary transcript-selection coding to existing or new themes,
  together with theme, quote, and document memos.
- Added undo and redo for manual edits and preservation of manually touched
  themes when analysis is run again.
- Added transcript coding stripes for reviewing overlapping theme coverage.
- Added optional local sentence-transformer embeddings and multilingual model
  selection when the NLP extra is installed.
- Added optional `kiwipiepy` morphology so Korean transcripts use content terms
  rather than raw particle-attached Hangul chunks.
- The optional NLP dependencies are available to source installations and are
  not bundled in the default portable ZIP. The portable app uses built-in
  TF-IDF analysis and Korean fallback tokenization without an online service.

## Verification

- Unit tests cover project round trips, manual editing, selection coding,
  reanalysis preservation, transcript offsets, semantic backend selection,
  Korean tokenization, and release metadata.
- The Windows portable archive is built from the tagged source and checked by
  launching the packaged desktop application.
