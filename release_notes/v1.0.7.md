# ThemeForge v1.0.7

## Added

- Added **Find from theme** and **Find from quote** controls for ranked review
  of related uncoded passages.
- Excluded passages whose source spans already overlap any coded quote while
  keeping identical text in another transcript eligible for review.
- Added source-tab highlighting for each selected suggestion.
- Accepted suggestions now preserve speaker, source, line, and character
  offsets and use the existing undo and project-autosave workflow.

## Similarity Method

- Source installations with local embeddings use normalized
  sentence-transformer vectors and cosine similarity.
- The standard app uses normalized TF-IDF cosine similarity as a deterministic
  local fallback without adding a mandatory dependency.
- Similarity values rank passages for researcher review. They are not
  probabilities, confidence scores, or automatic thematic codes.

## Verification

- Added tests for TF-IDF ranking, local-embedding ranking, embedding fallback,
  overlap exclusion, duplicate text across sources, and speaker preservation.
- Ran the complete test suite and desktop workflows for theme search, quote
  search, source highlighting, acceptance, autosave, and undo in light and dark
  modes.

## Portable NLP Scope

- Optional sentence-transformer and `kiwipiepy` dependencies remain available
  to source installations and are not bundled in the default portable ZIP.
- The portable app provides the new workflow through built-in TF-IDF cosine
  similarity without an online service.
