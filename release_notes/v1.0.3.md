# ThemeForge v1.0.3

## Updated

- Improved filtering for embedded interviewer prompts that appear inside
  pasted or extracted transcript text rather than as clean speaker turns.
- Split embedded speaker labels after sentence punctuation so collapsed text
  such as `Participant:` and `Admin:` is handled as separate turns.
- Replaced exact-overlap-only focus alignment with local BM25-style relevance
  scoring plus transcript-learned related terms.
- Added a small education-focused curriculum term expansion for curriculum,
  lesson, standards, assessment, training, planning, and design connections.
- Improved theme labeling so contextual phrases and domain labels are favored
  over generic words such as `little bit`, `people`, and `need`.

## Verification

- Regression tests confirm embedded interviewer prompts are excluded from
  themes, keywords, and quote evidence.
- Regression tests confirm curriculum-related training, peer collaboration,
  and administrative scheduling receive differentiated focus alignment.
- Regression tests confirm generic filler phrases do not become theme labels.
- Unit tests cover analysis behavior, imports, CLI multi-file use, release
  metadata, and UI view-model helpers.
- Compile checks cover the ThemeForge package, tests, and GUI launcher.
