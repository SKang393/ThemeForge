# ThemeForge v1.0.2

## Updated

- Fixed unlabeled transcript handling so consent or procedure sentences at the
  beginning of an imported file no longer cause all quote evidence to be
  removed.
- Keeps imported container labels such as `Unknown`, `Transcript`, `Document`,
  and `Page 1` eligible for quote extraction while still filtering explicit
  interviewer or moderator speaker labels.
- Added a regression test covering unlabeled transcripts that begin with
  procedure text and then contain substantive interview content.

## Verification

- Focused regression test confirms substantive quote units remain available
  after procedure sentences are filtered.
- Smoke reproduction confirms the same unlabeled transcript now returns quote
  evidence and suggested themes.
- Unit tests cover analysis behavior, imports, CLI multi-file use, release
  metadata, and UI view-model helpers.
- Compile checks cover the ThemeForge package, tests, and GUI launcher.
