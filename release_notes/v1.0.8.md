# ThemeForge v1.0.8

## Added

- Added theme-by-source and theme-by-speaker matrix documentation for quote
  counts and unique-span coverage.
- Added public metadata for two-project intercoder comparison, coder identity,
  and persistent/exportable coding audit events.

## Reliability Method

- Intercoder comparison applies to two `.tfproj` files with identical shared
  transcript text and fixed shared meaning units.
- Reports include per-theme percent agreement, Cohen's kappa, prevalence or
  undefined-kappa warnings, and side-by-side disagreements for researcher
  review.

## Verification

- Release metadata coverage now requires v1.0.8 across package metadata,
  README content, the Windows portable default version, and this release note.
- Full build and packaged GUI verification remain required before publishing a
  portable release.

## Portable Scope

- Optional sentence-transformer and `kiwipiepy` dependencies remain available
  to source installations and are not bundled in the default portable ZIP.
- The portable package scope remains local and offline, with no online service
  required for transcript text.
