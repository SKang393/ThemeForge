# ThemeForge v1.1.0

## Updated

- Added tabbed raw transcript viewing for multiple uploaded files.
- Kept one shared focus topic across the full multi-file analysis.
- Reworked the evidence panel to highlight raw transcript passages using each
  theme's color.
- Added previous and next quote navigation for the selected theme.
- Removed duplicate action controls so file selection, analysis, and export
  each appear once in the workspace.
- Added light and dark window modes.
- Added an About dialog with project, repository, archive DOI, license, and
  developer information.

## Verification

- Unit tests cover analysis behavior, imports, CLI multi-file use, release
  metadata, and UI view-model helpers.
- Compile checks cover the ThemeForge package, tests, and GUI launcher.
- Local UI model checks covered display palettes, quote navigation status,
  About text, and transcript tab labels.
