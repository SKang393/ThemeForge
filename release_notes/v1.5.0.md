# ThemeForge v1.5.0

## Changed

- Interviewer exclusion now recognizes `DRM` speaker labels before thematic
  quote units are generated.
- The local validation harness now covers four qualitative studies and fails
  when expected inputs, published tables, quote mappings, or reliability data
  are missing.
- Quote-level precision and recall use human-coded passages only as evaluation
  targets. Ground-truth passages are not reused as analysis examples.
- Quote assignment uses best-matching theme names and maximum one-to-one
  character-offset overlap.
- Published PDF validation extracts both themes and subthemes from the 4-H
  outcome table and verifies every autism GET and PET summary.
- Multi-coder validation round-trips coded projects through `.tfproj`, checks
  percent agreement and Cohen's kappa bounds, verifies prevalence warnings,
  and accounts for every reconciled disagreement direction.

## Verification

- Full `unittest` discovery and `compileall` pass.
- All four local validation datasets load with zero skipped inputs, zero
  transcript-artifact quote units, and no interviewer or coder-name leakage.
- Quote-level ground truth resolves completely for both applicable studies.
- Published-theme extraction returns the complete theme/subtheme collections
  used by the validation gate.
- Portable ZIP inventory and packaged application smoke checks passed.

## Portable Scope

- Optional sentence-transformer and `kiwipiepy` dependencies remain available
  to source installations and are not bundled in the default portable ZIP.
- The portable package remains local and offline, with no online service
  required for transcript text.
