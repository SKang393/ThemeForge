# ThemeForge v1.3.0

## Updated

- Added text-based PDF transcript input through a pure-Python PDF reader.
- Added optional researcher codebook import for deductive theme matching from
  CSV, TXT, Markdown, DOCX, RTF, and text-based PDF files.
- Improved Otter, Zoom, Word-style, and NVivo transcript parsing so speaker
  names, row numbers, timestamps, URLs, and transcript boilerplate do not
  become themes or quote evidence.
- Stored quote character offsets so the desktop app highlights the selected
  quote occurrence more accurately.
- Split codebook matching into a focused module for release maintainability.

## Verification

- Unit tests cover transcript parsing, PDF handling, codebook matching, CLI
  errors, release metadata, UI view-model helpers, and validation harness
  output.
- The validation harness checks named-speaker attribution, name leakage,
  transcript artifact leakage, theme coverage, and codebook quote plausibility
  across the local qualitative-study validation datasets.
