# ThemeForge v1.2.0

## Updated

- Added speaker-role profiling so named interviewers or moderators, such as
  real names attached to interview prompts, are excluded from theme generation
  and quote evidence.
- Merged duplicate same-label themes so related evidence appears under one
  theme instead of split repeated theme names.
- Added quote-selection rationale for each highlighted quote, including theme
  signals, focus-topic alignment, similarity score, and researcher-review
  reminder.
- Added quote rationale to Markdown and CSV exports.

## Verification

- Focused validation confirmed named interviewer prompts no longer appear as a
  theme or evidence source under peer collaboration.
- GUI smoke validation confirmed the Evidence panel shows quote rationale while
  navigating highlighted quotes.
- Unit tests cover analysis behavior, imports, CLI multi-file use, release
  metadata, and UI view-model helpers.
- Compile checks cover the ThemeForge package, tests, and GUI launcher.
