# ThemeForge v1.0.6

## Fixed

- Prevented the source CLI from exiting with `UnicodeEncodeError` after writing
  a report whose path contains Korean or other characters unsupported by the
  active Windows console encoding.
- Kept the real report path unchanged while rendering unsupported characters
  safely in the completion message.

## Verification

- Added a subprocess regression test that forces Windows `cp1252`, writes to a
  Korean report filename, and verifies exit code 0 without a traceback.
- Re-ran the complete test suite and the tagged Windows portable launch check.

## Portable NLP Scope

- Optional sentence-transformer and `kiwipiepy` dependencies remain available
  to source installations and are not bundled in the default portable ZIP.
- The portable app uses built-in TF-IDF analysis and Korean fallback
  tokenization without an online service.
